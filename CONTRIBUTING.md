# Contributing

1. Прочитай `AGENTS.md` (обязательно). Удаление — только с двойного OK человека.
2. Spec-first: без апрува спеки кода нет. Тесты из AC — до реализации.
3. Один AC за раз: тест зелёный → suite без регрессий → коммит.
4. Проверки перед PR: `python -m pytest -q`, `ruff check engine tests scripts`.
5. Каждый факт — с уверенностью /10; нет данных → `[нет данных]`.

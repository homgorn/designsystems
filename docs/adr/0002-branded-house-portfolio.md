# ADR 0002 — Branded House для портфеля Agent-Ready

- Статус: accepted (07.10.2026)
- Контекст: 12 продуктов P1–P12, аудитории пересекаются (DS-лиды, platform-инженеры).
- Решение: один мастер-бренд Agent-Ready; каждый paid имеет free-аналог; migration P2/P12 → P1/P4/P5 → P3/P7/P8/P6 → P9/P10 → P11.
- Следствие: общий narrative + атрибуция CC BY во всех экспортах.

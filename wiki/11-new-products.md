# 11. Слой синтеза новых продуктов (портфель Agent-Ready)

> Факты — `research/06-product-synthesis-2026-10-07.md`. Спека топ-3 — `specs/002-products/spec.md`.
> Архитектура портфеля: **Branded House** — один мастер-бренд Agent-Ready, все продукты под ним (аудитории пересекаются, эквити одно, миграция между продуктами — суть).

## Core narrative

Макросдвиг: дизайн-система стала API для агентов, но buy-in падает (32%), а доказательств нет (ROI 5%, 5/5 — ни у кого).
Тезис: мы — независимый слой выбора и проверки: каталог + считаемый индекс + tools + машинный доступ + платные результаты.
Наследуют все продукты: evidence-URL на каждое утверждение · свежесть с датой · free-аналог у каждого paid · машине — первым.

## Каскад (lane каждого — что делает и чего НЕ делает)

| Продукт | Lane | Не делает |
|---|---|---|
| Agent-Ready CI (P1) | Проверяет, соблюдает ли агент систему (hit-rate, галлюцинации) | Не генерирует UI |
| DESIGN.md Pack (P2) | Отдаёт глубину корпуса машине за 1 клик | Не агрегирует чужие файлы |
| Registry Pro (P3) | Дистрибуция компонентов + маппинги | Не хранит приватный код |
| ROI Autopilot (P4) | Непрерывный adoption + drift + one-pager руководству | Не заменяет аналитику продукта |
| VPAT-from-DS (P5) | Draft ACR из системы + evidence + coverage | Не подписывает ACR (это ревьюер) |
| Token Bridge (P6) | Миграция токенов в прод с PR | Не редизайнит бренд |
| Code Connect Packs (P7) | Маппинги Figma↔код под ключ | Не пишет компоненты |
| DTCG Loss CI (P8) | Гарантия миграции без потерь | Не авторing-тул |
| Multibrand Graph (P9) | Наследование брендов + per-brand pipeline | Не DAM |
| Native Parity CI (P10) | Паритет iOS/Android в CI | Не mobile-фреймворк |
| Agent-UI Kit (P11) | Компоненты агентного UI + skills | Не чат-бота |
| Benchmark Feed (P12) | Свежий версионированный фид индекса | Не разовые отчёты |

Миграция: P2/P12 (вход, free) → P1/P4/P5 (проверка и комплаенс) → P3/P7/P8/P6 (внедрение) → P9/P10 (масштаб) → P11 (новый UI-слой).
Конфликты: P4 vs P12 — разные покупатели (лид vs внешний разработчик), разводятся лицензией; P1 vs P8 — разные гейты (поведение агента vs потери токенов), живут в одном CI-ране.

## Стартовая тройка (почему)

P5 — комплаенс-бюджет, якоря $299/$1 490, дедлайны ADA 2027–2028 (8/10).
P1 — пустая клетка (продают 0), usage-модель подтверждена Figma (7/10).
P11 — 0/21 supply, прецедент paid-skills, строится из нашего реестра (7/10).

## Цены портфеля (якоря 2026)

Фид/драфт $49–299 · подписки $199–999/мес · паки $299–999/система · enterprise $15–50k/год · консалтинг $4–12k аудит, $8–20k/мес fractional.
Правило: у каждого paid — free-аналог (как `/products`).

## Уверенность

Структура портфеля 7/10 · якоря P5/P1 8/10 · P9/P10 5/10 (ниши реальны, готовность платить — гипотеза).

# 06. Как заработать: плейбук (синтез 01+02+03)

## Вариант A. Дожать оригинал (если это твой проект или партнёрство)

Порядок по ROI, всё из gaps отчёта 01: Stripe → `/services` → email на 5 точках → фикс MCP-ревизии → лимиты MCP → реестр 4→10. Потолок одного человека: ~$80–120k/мес на консалтинге, дальше — найм и смена позиционирования.

## Вариант B. Скопировать формулу в смежную нишу (рекомендуется для нового проекта)

Формула designsystems.one, разложенная на воспроизводимые шаги:

1. **Выбери узкую категорию, где выбора нет, а артефактов много.** Кандидаты из ниш §6 рынка: agent-ready аудит чужих ниш (design tokens для email? DS для игр?); eval-харнесс; a11y-conformance; мультибренд-слой.
2. **Собери корпус 50–150 единиц с нормализованной схемой** (slug/name/company/url/tagline + разбор). Наш `build_db.py` — готовый шаблон пайплайна.
3. **Придумай считаемый индекс 3–7 сигналов** с evidence-URL и датой ре-аудита. Балл + методика = цитируемость. Открой данные CC BY — это distribution, не потеря.
4. **Дай 2–4 бесплатных tools**, решающих боль категории, с API/curl-доступом (конкуренты-одностраничники API не дают — это ров).
5. **Машинный слой с первого дня:** llms.txt, JSON-API, MCP read-only, robots с явными AI-ботами. Трафик будущего — от агентов.
6. **Платный кит $49–199 one-time** (компоненты/токены/шаблоны + доказательства: тесты, ADOPTION.md, диагностика) — checkout подключать ДО анонса, не после.
7. **Консалтинг-упаковка параллельно:** `/services`, цены, бриф, календарь. При малом трафике консалтинг кормит, продукты масштабируют.
8. **Email-захват на каждом tool** — единственный актив, переживающий просадки SEO.
9. **Contributed-механизм** (POST-сабмит как у registry.directory) — свежесть без найма.
10. **Не делай:** affiliate (убивает независимость), экранные галереи (чужой рынок), гонку за объём трафика.

## Вариант C. Партнёрство вместо конкуренции

Слой «выбора и бенчмарка» перед Supernova/zeroheight; CC BY-встраивания индекса в курсы/блоги/агентные тулы (ссылки обратно); спонсорство вендоров не-баннерного формата ($1–5k/мес).

## Ценовые якоря 2026 (из отчетов)

Киты $99–349 разово · треки $199–499 · аудит $4–12k · воркшоп $2–5k · fractional $8–20k/мес · enterprise API $15–50k/год · seats инструментов $35–59/место · usage-кредиты как новый якорь.

## Уверенность

Структурные шаги — 7/10 (подтверждены тремя независимыми рисерчами). Цифры выручки — 5/10 (модель, не факт). Первый шаг любого варианта — верифицировать трафик (Plausible) и прогнать unit-экономику на реальных CR.

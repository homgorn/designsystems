# 05. Рынок 2026 (сжато; полный отчёт — research/02)

## TAM-спор: разброс 190×

$0.39 млрд → $8.4 млрд → $75.2 млрд за «design systems software» в зависимости от границы. Цитировать нельзя. Bottom-up: слой платформ (Figma $1.056 млрд FY2025, гайд $1.42 млрд FY2026, NDR 136%) · слой инфраструктуры DS (Zeplin $51.9M, Frontify $60.3M, Chromatic $5.6M, Supernova ×3 за год) → **[оценка] SAM ≈ $250–450M ARR (5/10)** · слой услуг $186 млрд (смежный).

## Стандарты и adoption

DTCG 2025.10 stable (28.10.2025): темы, P3/Oklch, алиасы, один файл → все платформы; 23 adopter'а. Токены: 84% команд (было 56%). Структура: primitive 90% / semantic 85% / **component 52%**. Автоматизации нет у **60%**; code→design — **11%**.

## Главный тренд: DS стала API для агентов

State of AI in DS (07.2026, 21 система): MCP у **20/21**, skills у 19, llms.txt у 15, Code Connect только у **3**. 15 «ai-native». Правила игры: контекст **компилируется** (Mantine из MDX на релизе), принуждение **структурное** (Polaris/Primer/shadcn-инструкции), evals публикуются (Atlassian, shadcn, Astryx — baseline бил 50/91). Ценовой якорь: seats → usage-кредиты. AI встроили **10%** команд, 46% экспериментируют; AI-документация — самая пустая ниша.

## Ресурсный кризис (DSR 2026, n=147)

Команда есть у 83%, полностью внедрена у **7%**; довольных buy-in **32%** (было 42%); недокомплект **61%**; Gartner — «Дно разочарования». Вывод: продавать результат (adoption, ROI, a11y), не артефакты.

## Деньги: enterprise-слой

Zeplin прибылен при $1.2M инвестиций; Frontify $60M; Supernova продаёт «AI-отряд» $10k/мес; OSS — витрина, монетизация расширениями (MUI X, Chakra Pro, daisyUI skills $); Uizard съедена Miro.

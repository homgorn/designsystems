# 04. Конкуренты (сжато; полный отчёт — research/03)

## Прямые (каталоги DS)

Into Design Systems (239+, конференция $499 — каталог как воронка) · userinterface.systems (187+2 676 ссылок) · designsystems.directory (244, один человек, Google Form) · DesignOps World (179+137+63, affiliate, счётчики расходятся) · **aidesign.guide** (183, AI-фильтры но не рейтинг, платные гайды — ближайший по духу) · awesome-design-systems (**25 370 ★**, статичен) · Component Gallery (2 671 пример) · **State of AI in Design Systems** (21 система, 200 affordances со сниппетами, MCP+SQLite+BibTeX — **самый опасный**, но это снимок, не живой индекс).

## Косвенные

**Галереи экранов:** Mobbin (~1.6M/мес, MCP платный) · Refero (MCP+Skill) · **Screenrove (бесплатный MCP+REST, измеренный DESIGN.md — та же формула на экранах)** · Land-book (2.98M, реклама) · SaaSFrame · Page Flows.
**Маркетплейсы:** Untitled UI ($129–$9 999) · UI8 · Envato (16M) / ThemeForest (12M) — другой товар (результат, не выбор).
**Инфраструктура:** Supernova ($35–45/место, MCP) · zeroheight ($49–59) · shadcn (open code + registry) · **registry.directory** (86 реестров, POST-сабмит — образец contributed-механизма) · Figma Community.
**AI-генераторы:** v0 (6M devs) · Lovable · Magic Patterns — смежный бюджет, не прямой конкурент.
**Микрогенераторы токенов (7 шт.):** все бесплатны, все без API — техническое отставание от designsystems.one.

## SWOT (одним абзацем)

**S:** связка каталог+аудит+tools+продукт; методология с self-score 4/5; CC BY-данные; агентный стек; сильные tools; числовая честность. **W:** трафик ×100–1000 ниже; нет contributed-каталога; 48 unknown; нет публичного MCP-при-«must have»; нет recurring; H1 «100 vs 120». **O:** 5/5 не занят; CC BY-встраивания; слой выбора перед Supernova/zeroheight; дефицит глубины; контент «выбор/миграция/цена». **T:** «все провалились»; дрейф галерей в MCP; shadcn-реестры; свежесть силами одного; органика одного автора.

## Три приоритета из отчёта

1. Read-only MCP + SQLite поверх JSON (дни работы).
2. Сабмит систем третьими лицами (API + форма).
3. Строгость уровня State of AI (закрыть 48 unknown, сниппеты с URL).
**Не делать:** экранные галереи; affiliate; гонка трафика с Land-book/Envato.

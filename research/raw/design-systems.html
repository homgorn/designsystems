About this library

This is a design systems library and directory of 120 real-world examples — enterprise systems like Carbon and Polaris, open-source component libraries like shadcn/ui and Ant Design, government standards like GOV.UK and USWDS, and startup systems. Unlike a plain list of links, every entry in the collection carries engineering facets (stack, token pipeline, source model), a screenshot, and a downloadable design.md — and the anchor systems get full editorial breakdowns.

Those design.md files are restated from each system's own documentation and token packages, never extracted from a rendered page. Each one opens with a provenance block listing the sources it was written from, the date those links were last checked, and how confident the values are — and says so plainly when a system publishes too little to be confident. They are re-checked each quarter alongside the Agent-Ready audit.

Use it as a showcase for inspiration, a catalogue for evaluation, or a research directory: filter by stack above, check which systems are agent-ready, or get a straight recommendation in which one to build on. The library is updated continuously and re-audited quarterly.

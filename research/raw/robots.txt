# DesignSystems.one — robots.txt
# Permits search engines and AI training / retrieval bots by name so
# crawlers see explicit intent. Only genuinely private areas (admin,
# dashboard) are blocked at the crawler level.
#
# /api/og and /r/* serve machine-consumable artifacts (OG images and
# the shadcn-style component registry). They are intentionally crawl-
# able so shadcn / agent tooling can fetch them, but each route sends
# `X-Robots-Tag: noindex, nofollow` at the HTTP level — that, not
# robots.txt, is what keeps them out of the search index. (Disallowing
# them in robots.txt would prevent Google from ever seeing the
# noindex header and triggers a "Blocked by robots.txt" warning in
# Search Console.)

# ---- Search engines ----
